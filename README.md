## CV

The Download CV buttons use `cv/Shafakat-Sayeedi-CV.pdf`. To update it, save the new PDF over the old one with the same file name.

## Built with

Plain HTML and CSS, with no framework or build step. It adapts to phones, tablets, PCs and TVs, and uses a dark green theme. `styles.css` holds the styling for every page, and `favicon.svg` is the browser tab icon. See [images/README.md](images/README.md) for changing the profile photo and background picture.

## Run it locally

Open `index.html` in any browser.
